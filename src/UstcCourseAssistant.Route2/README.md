# USTC 选课助手 · 路线二

当前版本：`2.1.0`，路线二正式版；在 `2.0.1` 的安全边界上优化课程任务输入、首次使用引导、关键活动记录和只读文字交互。

> 学生制作 · 非官方。非官方学生工具，与中国科学技术大学无隶属、合作或授权关系。仅供学生本人及少量同学私下免费使用，不公开发布。

## 界面结构

- 主导航包含“任务监测”“活动记录”“调试工具”和“账号与安全”。
- “课程影子”和“单门受控操作”完整保留在“调试工具”内。
- 教务系统按钮、登录保留选项和登录状态恢复为顶部紧凑操作条；下方采用左侧会话信息栏、右侧功能页面的两栏结构。
- 主程序与教务系统仍是两个独立窗口；启动时只出现主程序，点击“打开教务系统”后才显示校方网页。
- 蓝白浅色视觉系统集中定义按钮、输入框、标签、卡片、表格、状态色和危险操作样式。
- 使用用户选定的透明图标作为 exe、任务栏和两个窗口图标；蓝色横幅不再显示大 Logo，未使用校徽或学校官方组合标志。
- 任务表保留 24 像素空白行头与单选整行高亮；点击行头或只读单元格会建立当前行，教学班代码和冲突旧课单击即可直接输入，“启用”复选框一次点击即可切换。
- 输入框内按 `Delete` 只删除文字；未编辑输入框且已选中整行时，按 `Delete` 删除该任务，底部删除和优先级按钮继续作用于当前行。
- 真实操作黄色确认区位于左侧会话栏下方；任务页顶部只保留“开始监测 / 暂停 / 立即检查（不选课）/ 短状态”。
- 自定义秒数和运行时段输入框与检查间隔下拉框同高；任务行高为 34 像素，普通文字、编辑文字和启用复选框均垂直居中。
- 所有说明、状态、编号和活动记录继续可以直接选择复制，但只读文字不显示输入光标且使用普通箭头指针；表格继续支持 `Ctrl+C`。
- 新安装首次打开时显示六步被动新手引导，只能由“上一步 / 下一步 / 跳过 / 完成”推进，不会操作真实控件；左下角圆形问号可随时“查看新手指引”。
- 活动记录默认显示关键记录，可切换到全部记录；真实选课、退课和恢复事件整行加粗。
- 活动记录使用无插入光标的只读文档查看器；关键/全部视图分别缓存单段落文档，切换时不再销毁并重建上万个富文本段落，同时保留跨行选择复制。
- 监测或只读检查期间任务表仍禁止编辑，但代码与冲突旧课不再绘制通用禁用输入框的灰色圆角背景，只保留干净的只读文字外观。

## 当前能力

- 在独立的 WebView2 配置目录中打开教务系统，由用户本人完成统一身份认证和短信验证。
- 将与 `https://jw.ustc.edu.cn/` 匹配的会话 Cookie 临时复制到内存中的 `CookieContainer`。
- 通过只读请求确认内部学生编号和当前开放选课轮次。
- 读取当前已选课程和当前轮次可选课程。
- 对用户输入的一批完整教学班代码批量查询人数和上限。
- 程序输出文字可直接选择并复制；表格支持选择单元格后按 `Ctrl+C`。
- “操作与监测”和“教务系统”使用两个独立窗口，教务窗口关闭时仅隐藏，可从主窗口重新打开。
- 已登录时自动识别会话；课程影子读取也会在需要时自动补做会话验证。
- 支持选择是否在关闭程序后保留内置浏览器登录状态，并提供明确的退出教务登录按钮。
- 认证失效、接口异常或格式变化时停止验证并提示用户。
- 程序启动时只显示主操作窗口；用户点击“打开教务系统”后才创建并显示教务窗口。
- 对一个精确教学班执行只读预检查后，可由用户逐次确认一次真实选课或退课。
- 真实操作使用有限次数、带等待的结果轮询，并在结束后重新读取已选课程核验最终状态。
- 管理多个待选教学班、启用状态、优先级和用户明确填写的冲突旧课。
- 支持只读立即检查、定时监测、检查间隔和跨午夜运行时段。
- 支持可选的检查周期随机抖动；每轮重新抽取基准周期的 `2/3～4/3`，关闭后保持固定周期。
- 任务写操作严格串行；目标课明确失败时恢复本轮已经退掉的旧课，任何写入结果不确定时暂停整个监测。
- 任务配置只保存课程代码和普通运行设置；程序启动后永远不会自动开始真实监测。
- 只允许一个路线二进程运行，防止两个窗口同时监测或提交。
- 每个真实操作流程及步骤在提交前落盘；崩溃、断电、强制关闭、取消或结果不确定后，下次启动会锁定所有新操作，要求先只读读取实际状态并人工解除。
- 单门操作和任务引擎共用同一个非阻塞写入闸门，防止重复点击、两个功能并行和窗口关闭导致重复提交。
- 任务配置采用临时文件、磁盘刷新、原子替换和备份恢复；损坏时显式提示并尽量恢复。
- 脱敏本地运行日志只保留最近 14 天，不记录密码、验证码、Cookie、登录令牌、请求编号或完整服务器响应。
- 可选“开机自动启动程序”，默认关闭；启用后也只打开程序，不会自动验证、监测或选退课。
- 每次监测计时器都记录计划触发时间；若因休眠、Modern Standby 或系统长时间停顿而明显晚于计划触发，会在发送任何请求前暂停。
- 尚未开始真实写入的网络超时进入只读恢复等待；网络恢复后先验证学生身份和开放轮次，成功才从下一轮继续，不重放中断的读取请求。
- 已发送或可能发送选课、退课、恢复请求时，结果一律视为不确定，保持暂停并要求人工核对，不自动重试。
- 只有“旧课已确认退课成功、目标请求可证明从未开始”时，才允许在网络恢复后严格只读核对身份、轮次、目标课和旧课状态，并串行尝试一次恢复旧课；尝试后无论成功与否均保持暂停。身份或轮次不一致、状态读取失败、写入结果不确定时禁止自动恢复。
- “账号与安全”页可选择保存统一身份认证账号和密码；账号保存在普通本机偏好中，密码只写入当前 Windows 用户的凭据管理器。
- 自动登录默认关闭，保存密码不会自动启用。启用后会在 `https://jw.ustc.edu.cn/login` 有限等待并点击统一身份认证入口，再在 `id.ustc.edu.cn` 有限等待异步账号密码表单；凭据只在后者填写，而且一次登录流程最多自动提交一次。
- 检测到短信、验证码、新设备或二次认证时立即停止自动提交，由用户本人继续；程序不读取或保存验证码。
- 会话失效后即使重新登录成功，已经暂停的任务也不会自行恢复，结果不确定的选退课不会自动重试。用户主动退出登录后，本次运行内会显示抑制原因并停止自动登录；取消并重新勾选自动登录后才解除。

## 请求边界

只读客户端只允许：

- `GET /for-std/course-table` 及其同域重定向页面；
- `POST /ws/for-std/course-select/open-turns`。
- `POST /ws/for-std/course-select/selected-lessons`；
- `POST /ws/for-std/course-select/addable-lessons`；
- `POST /ws/for-std/course-select/std-count`。

阶段 C/D 共用的独立受控客户端只允许以下三个固定地址：

- `POST /ws/for-std/course-select/add-request`；
- `POST /ws/for-std/course-select/drop-request`；
- `POST /ws/for-std/course-select/add-drop-response`。

受控客户端不接受任意网址，只接受只读查询得到的学生、轮次和教学班数字 ID。每次只提交一个请求且绝不重试写入。单门操作必须通过预检查、勾选和二次弹窗；任务监测必须通过全局勾选和启动弹窗。任务引擎只处理用户明确填写的冲突旧课，执行“退旧课 → 选目标课 → 失败时恢复旧课”，并在每一步重新读取最终状态。任何不确定结果都会停止后续操作。

Cookie、密码、验证码和响应正文都不会写入普通配置或日志。WebView2 自己的浏览器配置保存在 `%LOCALAPPDATA%/USTC Course Assistant Route2/browser-profile`，与路线一完全隔离。

## 本地运行

```powershell
dotnet run --project src/UstcCourseAssistant.Route2/UstcCourseAssistant.Route2.csproj
```

阶段 A～E 当前可安全执行的实际验收以及既有正式版验收均已完成；无法自然触发的短信、OTP、新设备和二次认证分支保留安全停止逻辑与离线覆盖，不人为制造风险。当前正式版位于 `release/2.1.0/`。阶段 D 的“开始监测”仍会真实改变选课状态；构建、离线故障检查、界面回归检查、说明页检查、单实例检查与启动冒烟检查不会连接教务系统，也不会发送真实选退课请求。
