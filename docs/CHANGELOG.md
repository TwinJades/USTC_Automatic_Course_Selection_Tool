# 版本历史

版本号使用语义化格式：`主版本.次版本.修订`。

## 路线一

| 版本 | 内容 |
| --- | --- |
| 0.0.1 | 首个桌面界面与任务框架。 |
| 0.0.2 | 修复启动日志导致的立即退出。 |
| 0.0.3 | 接管教务系统打开的选课新窗口。 |
| 0.1.0 | 输入课程代码后自动筛选课程。 |
| 0.1.1 | 改进课程行定位与选课结果弹窗识别。 |
| 0.1.2 | “立即检查”改为只读；读取课程名称、已选状态与容量。 |
| 0.1.3 | 增加容量稳定性复核、课程标题提取与选课成功弹窗自动关闭。 |
| 0.2.0 | 从已选课程页批量只读核验，支持从全部课程页退课，锁定系统字段并自动关闭全部结果弹窗。 |
| 0.2.1 | 使用全页可见的“关闭/确定/完成”按钮关闭教务结果弹窗。 |
| 0.2.2 | 每次搜索前后显式清空课程关键词，避免残留筛选状态。 |
| 1.0.0 | 发布使用内置网页操作的路线一正式版。 |

## 路线二

| 版本 | 内容 |
| --- | --- |
| 2.0.0-alpha.9 | 增加单实例保护、真实操作事务记录与中断锁、统一写入保护、任务配置原子保存和恢复、14 天脱敏日志、默认关闭的开机启动及安全暂停；补充高低优先级冲突处理。 |
| 2.0.0-alpha.10 | 统一蓝白浅色界面、主导航与高级工具分层、紧凑登录状态卡、独立教务窗口外观、非官方说明和多尺寸应用图标。 |
| 2.0.0-alpha.11 | 调整顶部教务操作条与左会话/右功能两栏，精简横幅，登录状态黄灯使用 `#FFFF00`；任务表恢复 24 像素行头、整行高亮及复选框同步选行。 |
| 2.0.0-alpha.12 | 将真实操作确认区移入左栏，调整任务控制区顺序与短状态文字，统一三个输入框高度；“高级工具”更名为“调试工具”，任务行高改为 34 像素并使文字与编辑态垂直居中。 |
| 2.0.0-alpha.13 | 新增“账号与安全”页；账号保存到本机偏好，密码仅保存到 Windows 凭据管理器。可选自动登录默认关闭，只处理正常登录表单，遇短信、验证码或新设备验证立即停止；重新登录不恢复监测或重复不确定操作。 |
| 2.0.0-alpha.14 | 自动激活教务统一身份认证入口，有限等待异步表单且最多提交一次；仅在允许的认证域填写凭据，完善人工验证停止及主动退出后的自动登录抑制。 |
| 2.0.0-rc.1 | 发布候选版，补充偏好升级、账号不写入活动日志、普通配置无密码字段的离线检查及用户说明。 |
| 2.0.0 | 发布路线二正式版，设置正式版本元数据，提供 Windows x64 单文件应用。 |
| 2.0.1 | 增加休眠、Modern Standby 与系统长时间停顿后的计时器延迟保护；区分纯读取网络恢复和真实写入结果不确定。对已确认退旧课且目标请求从未开始的中断，增加严格核对后的一次旧课恢复尝试，恢复后保持暂停。 |
| 2.1.0 | 教学班代码与冲突旧课支持单击输入，启用复选框一次切换；保留整行选择及 `Delete` 删除任务。新增六步被动引导、默认关键活动记录及真实操作加粗显示；只读文字可复制且隐藏输入光标。监测锁定时输入框采用透明模板，活动记录使用缓存只读文档，支持大量日志切换与跨行连续复制。 |
| 2.2.0 | 增加启动 GitHub 更新检查、应用内下载校验和安全替换重启；增加多个独立北京时间预约、错过后补执行设置和剩余课程导入监测。监测支持多轮次，读取独立运行，真实操作按预约优先顺序串行执行；标题与版本同行，帮助和更新状态移至右上角。 |
