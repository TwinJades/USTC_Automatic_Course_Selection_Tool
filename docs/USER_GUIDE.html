快速上手

  1. 打开程序
    全新用户会看到六步说明；启动后不会自动监测。
  2. 打开教务系统
    在独立窗口中登录并识别会话。
  3. 添加课程任务
    填写完整教学班代码与必要的冲突旧课。
  4. 先做只读检查
    点击“立即检查（不选课）”核对课程与余量。
  5. 确认后监测
    核对无误，再勾选真实操作确认并开始。

  • 程序显示结果后，仍须回到教务系统人工确认最终状态。
完整使用说明

按实际使用阶段查找信息

这里收纳详细设置和异常处理。真实操作的总风险提醒只在首页集中展示。

1. 界面与任务

主要区域

  • 登录状态：显示内部学生编号、开放选课轮次和会话提示。
  • 任务监测：维护课程任务、运行设置并执行只读检查或监测。
  • 活动记录：默认查看关键事件；切换“全部记录”可查看最近 14 天的完整脱敏运行信息。
  • 调试工具：包含“课程影子”和“单门受控操作”。
  • 账号与安全：管理可选密码保存和自动登录。

配置任务

  • 点击“添加课程”后会新增一行，并把光标放入教学班代码。代码格和冲突旧课格单击即可直接输入，不需要先选中整行。
  • 教学班代码必须填写完整，例如 001683EX.01；“启用”复选框单击一次即可切换。
  • 数字越小优先级越高；可用“优先级上移/下移”调整。
  • 只启用确实准备监测的任务。
  • 冲突旧课填写你明确允许退掉的完整教学班代码；多个代码用逗号分隔，没有则留空。
  • 点击左侧空白行头或只读单元格可选中整行；此时按 Delete 可删除任务。在输入框内按 Delete 只会删除文字。
  • 可配置检查间隔、运行时段和可选的周期随机抖动（±1/3）。运行时段支持跨午夜。

新手指引与活动记录

只有完全没有旧偏好、任务、日志或浏览器资料的新用户会在首次打开时自动看到指引。指引只通过“上一步 / 下一步 / 跳过 / 完成”移动，不会替你打开网页、添加课程、勾选确认或启动监测。之后可点击左下角圆形问号重新查看。

活动记录默认显示验证、监测开始与停止、真实选课/退课/恢复等关键事件；真实操作整行加粗。需要排查详细过程时，再点击“全部记录”。关键和全部视图分别缓存只读文档，切换时不会重新生成全部文字行，并可跨越多行连续选择复制。

两种检查方式

立即检查（不选课）固定为只读，用于核对目标、余量、已选状态和冲突课匹配。

开始监测会在满足条件时执行真实操作，需要黄色区域确认和二次确认弹窗。

2. 登录与安全

  • 程序启动时只显示主窗口；点击“打开教务系统”后才显示独立教务窗口。
  • 正常登录后会自动识别只读会话，也可点击“验证只读会话”重试。
  • 保存账号密码是可选功能，自动登录默认关闭；保存密码不会顺带开启自动登录。
  • 账号保存在本机普通偏好中；密码只保存到当前 Windows 用户的 Windows 凭据管理器。
  • 自动登录只处理 USTC 教务登录入口和统一身份认证的正常账号密码流程，每次登录流程最多提交一次。
  • 遇到短信、验证码、OTP、新设备或二次认证时，自动提交会停止，由本人完成。
  • 登录成功只恢复会话识别，不会自动开始或恢复任务监测。
主动退出：点击“退出教务登录”后，本次运行会抑制自动登录。需要恢复时，在“账号与安全”中先取消、再重新勾选自动登录。

3. 真实操作与异常处理

选课、退课与换课

  • 单门受控操作必须先执行只读预检查，再勾选确认并通过二次弹窗。
  • 任务换课严格串行执行“退旧课 → 选目标课 → 目标失败时恢复旧课”。
  • 每个写请求只提交一次；响应不确定时不会猜测失败后重复提交。

网络、休眠与安全暂停

监测计时器若因休眠、Modern Standby 或系统长时间停顿而明显晚于计划触发，会在发送任何请求前暂停，避免短暂唤醒时继续监测。

尚未开始真实写入时，纯读取网络超时会进入等待；网络恢复后程序只做一次只读会话验证，确认学生身份和开放轮次一致后，从下一轮继续，不重放中断的读取请求。认证失效、身份或轮次不一致、状态读取失败会保持暂停。

选课、退课或恢复请求已经发送或可能发送时，结果视为不确定，禁止自动重试或恢复，必须由本人核对。

退旧课后的唯一受限恢复

只有程序已经确认旧课退课成功，并能证明目标课请求从未开始时，网络恢复后才会先只读核对账号、轮次、目标课未选和旧课未选。全部一致时可串行尝试一次恢复旧课；无论恢复成功、失败或结果不确定，程序都会继续暂停并要求人工确认。

红色中断保护

  1. 不要立即重复点击或重新启动监测。
  2. 登录教务系统，点击保护区中的只读核对操作。
  3. 根据显示结果回到教务网页人工处理或确认。
  4. 确认实际状态清楚后，再明确解除保护。

开机启动、合盖与电源设置

开机启动默认关闭；启用后也只打开程序，不自动监测。本应用不会读取或修改 Windows 合盖动作和全局电源计划，也不提供“保持唤醒”功能。电脑真正进入睡眠后程序无法继续检查；恢复后，明显延迟的监测计时器会先暂停。

4. 数据、隐私与常见问题

本机保存位置

普通数据位于：

%LOCALAPPDATA%\USTC Course Assistant Route2

  • preferences.json：普通偏好和账号文字，不含密码。
  • automation-settings.json：课程任务和运行设置，带备份恢复。
  • activity.jsonl：最近 14 天脱敏活动日志。
  • operation-journal.json：真实操作中断保护记录。
  • browser-profile：独立 WebView2 浏览器会话数据。

密码位于 Windows 凭据管理器，不在普通数据目录。程序不把密码、验证码、Cookie、登录令牌或完整服务器响应写入配置和日志。

安全清理

  1. 确认没有真实操作正在执行，也没有待核对的红色中断保护。
  2. 在“账号与安全”点击“删除已保存密码”。
  3. 关闭程序。
  4. 使用文件资源管理器将上述数据目录移入回收站；不要使用绕过回收站的永久删除方式。

常见问题

状态显示“等待运行时段”怎么办？

当前时间不在设置的开始—结束范围内。程序保持等待；检查时段设置，或到达时段后观察。顶部黄色圆点属于正常等待提示。

为什么登录成功后没有自动监测？

这是既定安全边界。登录只恢复会话识别；真实监测始终需要本人勾选黄色确认并点击“开始监测”。

为什么自动登录停止了？

可能检测到验证页面、页面未在有限时间内准备好、凭据错误，或你主动退出后仍处于抑制状态。按页面提示由本人继续；主动退出的抑制需取消再重新勾选自动登录。

出现“结果不确定”或红色保护怎么办？

不要重复提交。先通过只读核对获取当前状态，再回到教务系统人工确认；处理完成后才解除保护。

从早期实现到后续完善

相比路线一的改进

路线一是基于 WebView2 页面与 DOM 操作的早期实现和验证方案；路线二在其经验基础上继续完善。两者均为非官方学生工具。

更完整的任务管理

路线二完善了多课程启用状态、优先级、冲突旧课、运行时段、周期抖动及高低优先级冲突处理。

独立且可观察的教务窗口

主程序与教务系统保持两个独立窗口；用户可以直接观察校方页面，并随时从主程序重新打开教务窗口。

结构化只读核对

路线二通过会话桥接和固定请求边界读取轮次、已选课程、可选课程和人数，并提供课程影子与“立即检查（不选课）”。

单门受控操作

新增精确教学班预检查、逐次确认、有限结果查询和最终已选状态复核，用于明确的一次选课或退课。

统一真实操作保护

任务引擎与单门操作共用非阻塞写入保护；单实例机制避免两个路线二进程同时运行和提交。

中断与不确定结果处理

真实流程按步骤记录。崩溃、断电、取消或结果不确定后会锁定新写入，要求先读取实际状态并人工处理；只有可证明目标请求从未开始的退课中断，才允许严格核对后尝试一次恢复旧课。

计时与网络恢复边界

明显延迟的计时器会在请求前暂停；纯读取超时仅在网络恢复并通过一次会话核对后从下一轮继续。任何可能已发送的真实写入仍保持暂停，不会重复提交。

配置与本地记录增强

任务配置采用原子替换和备份恢复；活动日志脱敏并只保留最近 14 天。

受限制的自动登录

密码可选保存在 Windows 凭据管理器；自动登录只处理允许域名的正常表单，遇到验证立即交由本人。

更保守的启动行为

程序启动和可选开机启动都只打开主界面，不会自动开始监测；登录成功同样不会启动或恢复任务。

对比依据与边界

以上内容来自路线一与路线二源码、项目 README、版本记录及路线二交接文档。路线二减少了对页面切换和页面文字判断的依赖，但仍依赖校方系统、网络和未公开接口；它不代表官方支持，也不能保证换课或旧课恢复成功。
