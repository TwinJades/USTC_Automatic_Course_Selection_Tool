# USTC 选课助手

面向中国科学技术大学综合教务系统的非官方 Windows 桌面工具。

## 功能

- 管理多门课程任务、优先级、冲突旧课、检查周期和运行时段。
- 通过“立即检查（不选课）”核对课程、余量和已选状态。
- 经本人确认后监测课程余量，执行选课、退课和串行换课。
- 提供网络异常、休眠延迟、结果不确定时的安全暂停和中断保护。
- 支持任务配置备份恢复、最近 14 天脱敏活动记录和单实例保护。
- 可选保存账号密码并启用受限制自动登录；密码保存在 Windows 凭据管理器，遇验证码或二次认证时交由本人完成。

> 本工具可能执行真实选课或退课。请回到教务系统确认最终结果；换课及旧课恢复不保证成功。

## 下载

前往 [GitHub Releases](https://github.com/TwinJades/USTC_Automatic_Course_Selection_Tool/releases)，下载对应版本的 ZIP，解压后运行其中的 `USTC_Automatic_Course_Selection_Tool_<版本号>.exe`。

适用于 Windows 10/11 x64，需要 WebView2 Runtime。
