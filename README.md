# USTC 选课助手

面向中国科学技术大学综合教务系统的非官方 Windows 桌面工具。

## 功能

- 管理多门课程任务、优先级、冲突旧课、检查周期和运行时段。
- 通过“立即检查（不选课）”核对课程、余量和已选状态。
- 经本人确认后监测课程余量，执行选课、退课和串行换课。
- 设置多个独立定时抢课预约，按北京时间执行一轮；可将剩余课程导入监测并自动继续。
- 启动时检查 GitHub 正式版本，经本人确认后下载更新并自动替换、重新启动。
- 提供网络异常、休眠延迟、结果不确定时的安全暂停和中断保护。
- 支持任务配置备份恢复、最近 14 天脱敏活动记录和单实例保护。
- 可选保存账号密码并启用受限制自动登录；密码保存在 Windows 凭据管理器，遇验证码或二次认证时交由本人完成。

> 本工具可能执行真实选课或退课。请回到教务系统确认最终结果；换课及旧课恢复不保证成功。

## 下载

前往 [GitHub Releases](https://github.com/TwinJades/USTC_Automatic_Course_Selection_Tool/releases)，下载对应版本的 ZIP，解压后运行其中的 `USTC_Automatic_Course_Selection_Tool_<版本号>.exe`。

适用于 Windows 10/11 x64，需要 WebView2 Runtime。

## 定时抢课

登录并完成会话识别后，打开“定时抢课”，新建预约，填写日期、时间和课程列表，设置优先级与允许退掉的冲突旧课，再勾选授权并启用。尚未开放选课时也可建立预约；默认在执行时识别唯一开放轮次，存在多个轮次时需要自行指定。

预约和任务监测可以同时运行，真实选退课依次执行，到期预约优先处理。选择“导入监测”后，只追加仍未选中的有效课程，跳过重复课程，新课程按预约优先级排在已有任务后面。

请保持程序运行和电脑清醒。默认跳过关闭程序或休眠期间错过的预约；勾选“错过预约时间后，下次启动或休眠恢复时仍执行”后允许补执行。验证码、认证失败、轮次关闭或结果不确定时停止执行，需要本人处理。

## 更新程序

右上角图标显示检查结果，发现新版本后可查看发布说明并下载。安装会等待当前真实操作结束，保存预约和任务，然后重新启动。新程序文件名包含新版本号，开机启动路径自动更新，自行创建的快捷方式需要修改。应用内安装需要程序所在目录可写。
