# 🎓 USTC 选课助手

面向中国科学技术大学综合教务系统的非官方 Windows 桌面工具，持续检查课程余量，经本人授权后自动选课或换课，也支持定时抢课。

🧭 程序内置使用教程，零成本上手使用。

> ⚠️ 程序会执行真实选课、退课，请只授权本人确认的课程，并到教务系统核对最终结果。换课及旧课恢复均不保证成功。本工具与学校无隶属、合作或授权关系。

## 📥 下载与运行

前往 [GitHub Releases](https://github.com/TwinJades/USTC_Automatic_Course_Selection_Tool/releases) 下载 ZIP，解压后运行 `USTC_Automatic_Course_Selection_Tool_<版本号>.exe`。

需要 Windows 10/11 x64、WebView2 Runtime，以及能够访问学校教务系统的网络。

## 🔍 自动监测

持续检查课程余量，在满足条件时自动执行已授权的选课或换课任务。

| 功能 | 说明 |
| --- | --- |
| 📚 多课程、多轮次监测 | 统一管理多门课程，持续检查余量；每门课程可指定所属选课轮次。 |
| 🥇 优先级处理 | 按优先级依次执行任务；高优先级课程选中后，停用与其冲突的低优先级任务。 |
| 🔁 自动换课 | 支持为目标课程指定允许退掉的旧课，有余量时依次执行退课和选课；<br>选课失败且满足恢复条件时，尝试恢复本轮已退旧课。 |
| 🕒 灵活检查频率 | 支持 5 秒、15 秒、60 秒和自定义间隔，可启用每轮 ±1/3 的随机抖动。 |

此外，支持每日运行时段（含跨午夜，时段外保持等待），可只读核对课程、余量和已选状态，并查看任务状态与真实选退课记录。读取网络中断后，经身份和轮次验证可继续监测；登录失效、休眠或操作结果不确定时暂停，真实选退课请求不会自动重试。

监测需要保持程序运行和电脑清醒。重新启动或重新登录后，持续监测需要本人重新启动。

## ⏰ 定时抢课

支持多个独立的北京时间预约，每个预约执行一轮选课，可将剩余有效课程导入持续监测。支持设置错过预约后的补执行行为；执行时需要程序运行、电脑清醒。

## ✨ 详细功能表

| 功能 | 说明 |
| --- | --- |
| 自动监测 | 持续检查多门课程余量，按优先级处理任务，支持自定义检查间隔、随机抖动和运行时段。 |
| 课程检查 | 单次核对课程、余量和已选状态，不执行选课或退课。 |
| 课程换课 | 指定允许退掉的冲突旧课，检测到目标课余量后依次执行退课和选课。 |
| 定时抢课 | 设置多个独立的北京时间预约，执行一轮选课，可将剩余课程导入持续监测。 |
| 活动记录 | 保留最近 14 天的脱敏记录，支持查看关键事件、全部记录和复制文字。 |
| 账号管理 | 可选保存账号、保留登录状态和自动登录；密码保存在 Windows 凭据管理器，验证码及二次认证由本人完成。 |
| 配置保存 | 自动保存任务配置，支持备份恢复。 |
| 自动更新 | 启动时检查正式版本，经本人确认后下载、安装并重新启动；安装需要程序所在目录可写。 |
| 使用引导 | 首次启动提供操作引导，右上角问号可以重新打开。 |
| 启动设置 | 支持开机启动和单实例保护；开机启动默认关闭，启动程序不会自动恢复持续监测。 |
| 调试工具 | 提供课程只读核对和单门受控操作。 |
